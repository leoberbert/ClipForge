ClipForge for Windows x86_64

Rust is not required to run this build. Extract this zip anywhere and run
clipforge.exe. The app will offer to install missing media tools with winget,
or you can copy the install commands from the setup screen.

Required:

- yt-dlp
- FFmpeg, which also provides ffprobe and ffplay

Recommended:

- Deno, for current YouTube extraction
- VLC or MPV, for the preview window

ClipForge para Windows x86_64

Esta versão não exige Rust. Extraia este zip em qualquer pasta e execute
clipforge.exe. O app oferece instalar as ferramentas de mídia que faltam com
o winget, ou você pode copiar os comandos na tela de instalação.

Necessário:

- yt-dlp
- FFmpeg, que também traz o ffprobe e o ffplay

Recomendado:

- Deno, para a extração atual do YouTube
- VLC ou MPV, para a janela de pré-visualização

ClipForge for Windows x86_64

Rust is not required to run this build. Install these programs and make
sure their directories are on PATH before loading or exporting a video:

- yt-dlp
- FFmpeg, which also provides ffprobe and ffplay
- VLC or MPV, for the preview window

Deno is recommended. Current yt-dlp releases use it to read YouTube pages;
without it, fewer formats may be available.

yt-dlp and FFmpeg stay outside this archive so they can be updated on
their own.

ClipForge para Windows x86_64

Esta versão não exige Rust. Antes de carregar ou exportar um vídeo,
instale estes programas e deixe as pastas deles no PATH:

- yt-dlp
- FFmpeg, que também traz o ffprobe e o ffplay
- VLC ou MPV, para a janela de pré-visualização

O Deno é recomendado. As versões atuais do yt-dlp usam ele para ler as
páginas do YouTube; sem ele, pode haver menos formatos disponíveis.

yt-dlp e FFmpeg ficam de fora deste arquivo para serem atualizados
separadamente.
